# Diagramas

Esta pasta deve conter o diagrama final da arquitetura.

Formatos recomendados:

- Mermaid;
- PNG exportado;
- SVG vetorial;
- arquivo editable da ferramenta utilizada.

O diagrama deve mostrar:

- endpoints Windows;
- Wazuh Server;
- rede interna;
- fluxo Sysmon;
- fluxo Wazuh Agent;
- conta de analista;
- hosts de origem e destino.
