# Scripts

Esta pasta guarda scripts repetiveis usados no laboratorio.

## Scripts esperados

- validacao da configuracao do Sysmon;
- coleta controlada do estado do Defender;
- consulta de eventos Windows;
- exportacao sanitizada de evidencias;
- verificacao de persistencia;
- limpeza controlada dos cenarios.

Todos os scripts devem ser executados em ambiente autorizado e registrados no incidente.
