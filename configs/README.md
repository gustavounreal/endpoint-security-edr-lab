# Configuracoes

Coloque nesta pasta apenas configuracoes sanitizadas e versionadas.

## Arquivos recomendados

- fragmento do `ossec.conf`;
- configuracao ativa do Sysmon;
- regras locais de deteccao;
- regras Sigma;
- exportacao sanitizada de regras Wazuh;
- manifesto de versoes das ferramentas.

Não publicar chaves, tokens, senhas, dominios internos privados ou dados pessoais.
